# 🍔 Python Food Delivery System

A Python-based food delivery system project developed to practice **Object-Oriented Programming (OOP)** concepts through a real-world application scenario.

The project represents the basic structure of a food delivery platform, including customers, restaurants, menu items, orders, and delivery partners.

## 📌 Project Overview

Food delivery platforms involve multiple entities that work together to manage customers, restaurants, food items, and orders. This project models these entities using Python classes and object-oriented design principles.

**Objective:** To strengthen Python programming and OOP skills by building a structured food delivery system.

## ✨ Project Components

- **User & Customer:** Represents users interacting with the platform.
- **Restaurant:** Represents restaurants participating in food delivery.
- **Menu Items:** Models food items available on restaurant menus.
- **Order:** Represents food order information.
- **Delivery Partner:** Represents the delivery personnel.

*Note: These components describe the intended system structure; not all functionality may be implemented yet.*
