# 🍔 Food Delivery System

## 📌 Project Overview

The **Food Delivery System** is a Python-based project designed to simulate the basic operations of an online food ordering application. It allows users to explore restaurant menus, select food items, place orders, calculate bills, and manage order status.

The project demonstrates Object-Oriented Programming (OOP) concepts through classes, objects, methods, and encapsulation.

## 🎯 Objectives

- Simulate an online food ordering process.
- Manage customers, restaurants, menu items, and orders.
- Calculate bills with GST and packaging charges.
- Track order status.
- Verify orders using OTP validation.
- Apply Python OOP concepts to a real-world use case.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Concepts:** Object-Oriented Programming (OOP)
- **Core Concepts:** Classes, Objects, Constructors, Encapsulation, Methods, and Conditional Statements

## ✨ Features

- **Customer Management:** Store customer information.
- **Restaurant Management:** Manage restaurant details and food menus.
- **Menu Management:** Display food items and their prices.
- **Order Management:** Create and manage customer orders.
- **Bill Calculation:** Calculate the subtotal, 5% GST, and ₹20 packaging fee.
- **Order Status Tracking:** Maintain and update the order status.
- **OTP Verification:** Verify orders using OTP validation.
- **Estimated Delivery Time:** Display an estimated preparation or delivery time of 30 minutes.

## 🧾 Billing Formula

The total bill is calculated using the following formula:

- Subtotal = Sum of the prices of selected items
- GST = 5% of subtotal
- Packaging Fee = ₹20

**Total Bill = Subtotal + GST + Packaging Fee**

### Example

| Description | Amount |
|---|---:|
| Food Subtotal | ₹200 |
| GST (5%) | ₹10 |
| Packaging Fee | ₹20 |
| **Total Bill** | **₹230** |
